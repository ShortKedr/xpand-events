# Changelog

## [1.0.0-rc.1] - 2026-07-14

- Added deterministic synchronous signals with stable priority and disposable
  subscriptions.
- Added Unity lifecycle ownership, destroyed-object handling, main-thread
  dispatch, and ScriptableObject channels.
- Added Edit Mode, Play Mode, Mono, IL2CPP, Android, WebGL, allocation, and real
  consumer adoption validation.


## [0.7.0-alpha.1] - 2026-07-14

- Added the initial UPM package layout and assembly definitions.
- Added Core signals as ordinary AOT-friendly source.
- Added composite lifecycle ownership and `SignalListenerBehaviour`.
- Added destroyed-`UnityEngine.Object` aware subscription overloads.
- Added an explicit main-thread dispatcher and optional ScriptableObject channels.
- Added Edit Mode, Play Mode, and sample sources.
